## 🎯 Projeto Final: AI in Games

O projeto final é um site educativo sobre **Inteligência Artificial em Videogames** que inclui:

### Características Principais:
- **Design Responsivo** - Funciona em dispositivos móveis e desktop
- **Navegação Interativa** - Menu hambúrguer para dispositivos móveis
- **Animações CSS** - Efeitos visuais e transições suaves
- **Carregamento Lazy** - Otimização de imagens
- **Formulário Interativo** - Sistema para compartilhar jogos favoritos
- **Timeline Visual** - Evolução da IA através das gerações de consoles

### Páginas do Projeto:
1. **Página Principal** - Introdução ao tema e pioneiros da IA em games
2. **Evolução** - Timeline histórica da IA nos videogames
3. **Interativo** - Formulário para os usuários compartilharem jogos favoritos

### Tecnologias Utilizadas:
- **HTML5** - Estrutura semântica
- **CSS3** - Flexbox, Grid, animações, responsividade
- **JavaScript** - Interatividade, formulários, animações
- **LocalStorage** - Persistência de dados
- **Intersection Observer API** - Animações baseadas em scroll

## 🛠️ Tecnologias e Conceitos Abordados

### HTML
- Estrutura semântica
- Formulários e validação
